# OMANDO

A production-ready, anonymous AI-powered mental-health SaaS platform designed to detect and monitor psychological disorders through non-intrusive smart assessments. The ecosystem features a comprehensive documentation portal, an AI companion, and a multi-user tracking dashboard allowing families or guardians to securely monitor user progress.
